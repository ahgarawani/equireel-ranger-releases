# Release Metadata Workflow

This repository stores metadata and checksums for Ranger installer releases.

## Inputs Produced by Private Source Repo
- `dist/Ranger-Setup.exe` (release asset)
- `dist/manifest.json` (generated by release pipeline)
- `dist/Ranger-Setup.exe.sha256` (installer checksum)

## Public Repo Update Steps
1. Copy `dist/manifest.json` to repository root as `manifest.json`.
2. Copy `dist/Ranger-Setup.exe.sha256` to `checksums/Ranger-Setup.exe.sha256`.
3. Commit and push metadata updates.

```bash
git add manifest.json checksums/Ranger-Setup.exe.sha256
git commit -m "chore: publish release metadata for vX.Y.Z"
git push origin main
```

4. Create release tag `vX.Y.Z` and upload installer asset `Ranger-Setup.exe`.

## Validation
1. `manifest.json` has `version`, `installer_url`, `sha256`, `min_version`.
2. Root manifest URL resolves on `main` branch.
3. Installer URL points to matching GitHub release tag.
